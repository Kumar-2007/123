# Notice Board App 📌

A simple, responsive, and clean Flutter application for managing notices and announcements. Built with Material Design 3 and State Management.

## 📱 Features

- **View Notices**: Displays a clean list of announcements with custom icons.
- **Add New Notice**: Interactive dialog allowing users to create and append new notices instantly.
- **Delete Notice**: Option to remove old or resolved notices.
- **Empty State**: Displays a friendly placeholder screen when no notices are available.
- **Material 3 UI**: Clean user interface built using modern Flutter widgets.
